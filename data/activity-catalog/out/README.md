## โฟลเดอร์ภาพ (`ภาพ/`) — พร้อมใช้ทันที

- `ภาพ/1_ที่พัก/<จังหวัด>/<ที่พัก>/<ประเภท>_<ลำดับ>_<รหัส>.jpg` — ประเภท = ภายนอก/ป้าย/มุมสูง · ล็อบบี้ · ห้องพัก · สระว่ายน้ำ · ห้องประชุม · ห้องอาหาร · สิ่งอำนวยความสะดวก
- `ภาพ/2_กิจกรรม/<รหัส หลักสูตร>/<เซสชัน>/<ลำดับ>_<รหัส>.jpg` — ภาพที่ต้องตรวจสิทธิ์อยู่โฟลเดอร์ `ตรวจสิทธิ์ก่อนใช้`, ภาพลายน้ำเว็บอื่นอยู่ `ห้ามใช้`, ภาพซ้ำอยู่ `_ภาพซ้ำ (ไม่ต้องใช้)`
- ลำดับในชื่อไฟล์ = คอลัมน์ "ลำดับ" ใน `05_photos.csv` · รหัสภาพ = ชื่อไฟล์ในเว็บ (`web/photos/<รหัส>.jpg`, ภาพย่อ `t_<รหัส>.jpg`)

## สำหรับทีมพัฒนาเว็บ — ดึงข้อมูลตรงจุด

```js
const cat = await (await fetch("eqcamp-catalog.json")).json();
// กิจกรรมหลักของหลักสูตร ที่ใช้จริงในโปรแกรม 2 วัน 1 คืน
cat.activities.filter(a => a.code === "PL MAT 0107" && a.level === "หลัก" && a.durs.includes("2 วัน 1 คืน"));
// ภาพฐานกิจกรรมของหลักสูตร ที่ใช้ได้เลย (ไม่ซ้ำ)
cat.photos.filter(p => p.courses.includes("PL MAT 0107") && p.session === "station" && p.use === "ใช้ได้" && !p.duplicate_of);
// ภาพที่พักในจังหวัด แยกตามประเภท
cat.photos.filter(p => p.kind === "ที่พัก" && cat.venues.find(v => v.name === p.venue)?.province === "ชลบุรี");
```

ฟิลด์สำคัญ: `activities[].code/name/level/category/progs/durs/minutes/in_real/notion/notion_status/programs` · `photos[].id/file/session/session_th/scene/courses/programs/venue/use/flags/duplicate_of` · `venues[].name/province/area/photos/comp/gap/ids` · `rows[]` = ทุกแถวตามต้นฉบับ
