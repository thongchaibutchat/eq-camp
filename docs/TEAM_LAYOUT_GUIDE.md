# คู่มือทีม — จัดวางเอกสารค่ายให้ถูกต้องและเป็นมืออาชีพ

คู่มือนี้อธิบาย "หน้าตาที่ถูกต้อง" ของเอกสารที่ระบบสร้าง และสิ่งที่ทีมต้องเตรียม
เพื่อให้ได้ผลลัพธ์ตรงตามตัวอย่างทุกครั้ง — ไม่กระโดดข้าม ไม่ฟอนต์เพี้ยน

---

## 1. ฟอนต์ — ไม่ต้องกังวลเรื่องตัวหนา/ตัวใหญ่ผิดอีก
ทุกไฟล์ Word **ฝังฟอนต์ TH Sarabun New มาในตัวแล้ว** เปิดที่เครื่องไหนก็หน้าตาเหมือนกัน
แม้เครื่องนั้นไม่ได้ติดตั้งฟอนต์ (เมื่อก่อนที่ตัวหนาไปทั้งแผ่น เกิดจากเครื่องไม่มีฟอนต์)
- **ตัวหนา ใช้เฉพาะหัวข้อหลักเท่านั้น** (เช่น วัตถุประสงค์การเรียนรู้ / กิจกรรมเชิงบูรณาการ / กำหนดการ)
- เนื้อหา เวลา รายการในกำหนดการ และรายการราคา = ตัวปกติเสมอ

## 2. หัวกระดาษ (เลือกตามภาคที่จัดกิจกรรม)
ระบบเลือกหัวกระดาษจากจังหวัดสถานที่จัดอัตโนมัติ เส้นสีน้ำเงินใต้หัวกระดาษ **เต็มความกว้าง ไม่ขาด**
| ภาค | ที่อยู่บนหัวกระดาษ |
|---|---|
| กลาง (กรุงเทพฯ/ปริมณฑล) | 523 ม.4 แขวงบางปะกอก เขตราษฎร์บูรณะ กรุงเทพมหานคร 10140 |
| อีสาน (สำนักงานใหญ่) | 289/69 ไพรเวท พาร์ค วิลล์ ม.4 ต.หนองบัว อ.เมือง จ.อุดรธานี 41000 |
| เหนือ | 62 ม.10 ต.ป่าไผ่ อ.สันทราย จ.เชียงใหม่ 50210 |
| ใต้ | *ยังไม่มีที่อยู่สาขาภาคใต้* → ใช้ที่อยู่อุดรฯ ชั่วคราว (ส่งที่อยู่จริงให้ทีมพัฒนาเพื่ออัปเดต) |

> ถ้ามีที่อยู่สาขาใหม่ ส่งให้ทีมพัฒนา **ห้ามพิมพ์เดาเอง** — ที่อยู่อยู่ในไฟล์เดียว (`src/letterhead-full-data.ts`)

## 3. หน้าแรก (ปกโปรแกรม) — ต้องพอดี 1 หน้า
ลำดับตายตัว: รหัส PL → ชื่อหลักสูตร (ไทย + อังกฤษ) → **วัตถุประสงค์การเรียนรู้ (เลข 1-4)**
→ จำนวน/วิทยากร/ระยะเวลา → กิจกรรมเชิงบูรณาการ → บูรณาการการเรียน
- รหัส PL อ้างจากเลขหลักสูตรจริงเท่านั้น (เช่น `PL STM 0101/2569`) — ไม่พิมพ์เดา

## 4. หน้ากำหนดการ
- หัวข้อ **"กำหนดการ" อยู่กึ่งกลางเสมอ** ตามด้วยชื่อหลักสูตรไทย/อังกฤษ, โรงเรียน, วันที่(ถ้ามี), สถานที่(ถ้ามี)
- กิจกรรมดึงจาก **หลักสูตรที่เลือก** เสมอ (ค่ายดาราศาสตร์ = กิจกรรมดาราศาสตร์, กลางคืน = ส่องกล้องดูดาว ฯลฯ)
- ปิดท้ายกำหนดการมี **"หมายเหตุ : กำหนดการอาจจะเปลี่ยนแปลงตามความเหมาะสม"** ในบรรทัดถัดไปเสมอ

## 5. ราคา & งบประมาณ
- แถบราคา = กล่องกึ่งกลาง: ราคาปกติ (ขีดฆ่าสีเทา) → **ลดเหลือเพียง … = สีแดงตัวหนา เด่น**
- ตามด้วย "รายละเอียดงบประมาณมีดังนี้" เรียงรายการตามลำดับ ไม่สลับไปมา

## 6. ภาพประกอบ (สำคัญ — แต่ละชุดขึ้นหน้าใหม่เสมอ)
ทุกหัวข้อภาพเป็น **ตัวหนา กึ่งกลาง** และกริด **6-8 รูปติดกัน 2 คอลัมน์** คมชัด ไม่แตก ขนาดเท่ากัน

### 6.1 ภาพกิจกรรม — หัวข้อ "ตัวอย่างภาพกิจกรรม"
- ระบบดึงภาพจริงของหลักสูตรให้อัตโนมัติ (ถ้ามีในคลัง) หรือทีมอัปโหลดเองในแท็บ 6
- ใช้ภาพแนวนอนคุณภาพดี 6-8 รูป (ปัจจุบันบางหลักสูตรมี < 6 รูป → ทีมเติมใน Drive)

### 6.2 ภาพที่พัก — หัวข้อ "ตัวอย่างภาพบรรยากาศที่พัก \<ชื่อที่พัก\>" (เฉพาะค่ายพักค้าง)
อยู่หน้าหลังสุด อัปโหลด **8 รูป ตามลำดับนี้เสมอ**:
1. ป้ายชื่อโรงแรมด้านหน้า + มุมสูง — **2 รูป**
2. ห้องพัก — **2 ห้อง (2 รูป)**
3. สระว่ายน้ำ / สิ่งอำนวยความสะดวก — **2 รูป**
4. ห้องประชุม / ห้องสัมมนา — **2 รูป**

> ใช้ภาพที่มีสิทธิ์เผยแพร่เท่านั้น (สื่อทางการของโรงแรม/ภาพทีมถ่ายเอง) — ห้ามดึงภาพลิขสิทธิ์จากเว็บ

### 6.3 ภาพเซ็ต STEAM — หัวข้อ "ตัวอย่างภาพกิจกรรมค่าย STEAM"
ใส่อัตโนมัติ **เฉพาะค่าย STEAM (PL STM 0101)** เท่านั้น ค่ายวิทย์อื่นจะไม่มี

## ขั้นตอนทำงานให้ได้ผลตามตัวอย่าง
1. วางบรีฟ → กดสร้าง → ตรวจแถบสรุป (ใช้แล้ว/ยังขาด)
2. ผูกหลักสูตรจริงในแท็บ "ฐานข้อมูลค่าย" เพื่อให้กิจกรรม/ภาพตรงธีม
3. ค่ายพักค้าง: อัปโหลดภาพที่พัก 8 รูปตามข้อ 6.2
4. กด **"บันทึก PDF"** หรือ **"ครบชุด 4 ไฟล์"** แล้วเปิดตรวจทุกหน้าก่อนส่งลูกค้า

## สิ่งที่ยังต้องให้ทีมเติม (ส่งให้ทีมพัฒนา)
- ที่อยู่สาขาภาคใต้ (และภาคกลางถ้ามีสาขาย่อยอื่น)
- ภาพกิจกรรมจริงของหลักสูตรที่ยังไม่มี: ธรณีวิทยา (GEO 0112), นิติวิทยาศาสตร์ (FOR 0110), Pre-genius (PRE 0105)
- ภาพเพิ่มให้ครบ 6-8 รูป/หลักสูตร สำหรับหลักสูตรที่ยังมีน้อย
- รายละเอียดกิจกรรม 267 รายการที่ยัง "รอตรวจ" (ขั้นตอน/อุปกรณ์/เวลา/ระดับชั้น) ใน MASTER sheet
