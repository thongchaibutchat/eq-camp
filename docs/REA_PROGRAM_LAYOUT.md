## 1. โครง/ลำดับตายตัว (โผล่ทุกครั้ง)
**หน้า 1 (ปก)**
1. รหัสเอกสาร `PL xxx 0000/2569` ชิดขวา ตัวปกติ — **หน้าแรกหน้าเดียว**
2. `หลักสูตร “ชื่อไทย”` กลาง 18 pt หนา · บรรทัดถัดไป `( English Name )` กลาง 18 pt หนา
3. **วัตถุประสงค์การเรียนรู้** (16 หนา) → 4 ข้อ รูป `1.ข้อความ` (ไม่เว้นวรรคหลังจุด) ย่อหน้าแรกเยื้อง 1.27 ซม. บรรทัดต่อไปชิดขอบ
4. `จำนวน` / `วิทยากร` / `ระยะเวลาอบรม` — ป้ายตัวหนา + แท็บ (ค่าเริ่มที่ 1.5 นิ้ว) **ไม่ใช่ตาราง**
5. **กิจกรรมเชิงบูรณาการ** → รายการ `1.กิจกรรม…` เยื้องทั้งบล็อก 1.27 ซม.
6. **บูรณาการการเรียน (Instruction Integration)** → 6 ข้อ `1.บูรณาการ…` เยื้องทั้งบล็อก

**หน้ากำหนดการ (ขึ้นหน้าใหม่)** — หัวข้อทั้งก้อน 18 pt หนา กึ่งกลาง:
`กำหนดการ` / `“ชื่อไทย”` / `( English )` / โรงเรียน / วันที่ / `ณ สถานที่`
- `วันที่ n` = **ขีดเส้นใต้** ตัวปกติ 16 pt (ไม่ใช่แถบสี)
- แถว = `เวลา<แท็บ 1.5 นิ้ว>รายการ` 16 pt ธรรมดา; รายละเอียดใต้รายการเยื้องตรงคอลัมน์รายการ
- ปิดท้าย: `หมายเหตุ : กำหนดการอาจจะเปลี่ยนแปลงตามความเหมาะสม` **สีแดง**

**หน้าราคา (ขึ้นหน้าใหม่)**: `ราคาปกติ X ` + `ลดเหลือเพียง Y บ./ท่าน`(แดง) → `รายละเอียดงบประมาณมีดังนี้` → `-  รายการ`
**หน้าภาพ**: `ภาพกิจกรรม` กลาง → กริด 2 คอลัมน์ 8 รูป

## 2. กิจกรรมเชิงบูรณาการ — หลักการ (ห้ามใส่ชื่อกิจกรรมเปล่า ๆ)
เดินตาม **วงจรการเรียนรู้ 5 ขั้น** และ **ทุกข้อขึ้นต้นด้วยคำว่า "กิจกรรม"**:
| ขั้น | หน้าที่ | ที่มาในระบบ | ตัวอย่างจริง |
|---|---|---|---|
| 1 | อุ่นเครื่อง/สร้างสัมพันธ์ | กิจกรรม opening ของหลักสูตร + `(กระบวนการสันทนาการสร้างสัมพันธ์)` | กิจกรรม" Reboot Your Brain" (กระบวนการสันทนาการสร้างสัมพันธ์) |
| 2 | กระตุ้นความคิด | คงที่ | กิจกรรมระดมสมองประลองปัญญา |
| 3 | ลงมือที่ฐานการเรียนรู้ | กิจกรรม core ของหลักสูตรที่เป็น Station/Mission/Quest/Challenge/ฐานการเรียนรู้ ไม่มี → ค่าคงที่ | กิจกรรม "Creative Learning Station" |
| (ภาคค่ำ) | เฉพาะค่ายพักค้าง | กิจกรรม night ของหลักสูตร | — (ยังไม่มีเอกสารจริงยืนยัน) |
| 4 | สะท้อนคิด | คงที่ | กิจกรรมระดมสมอง ถอดบทเรียน |
| 5 | วัดผล | คงที่ | กิจกรรมทดสอบหลังการเรียนรู้ (After Action Review : AAR) |
- ชื่อที่ไม่ได้ขึ้นต้นด้วย "กิจกรรม" → ระบบแปลงเป็น `กิจกรรม “ชื่อ”` (`asKijakam` ใน `compose`)
- ตัดคำต่อท้าย EP./Part/(ต่อยอด) ออกในหน้าปก

**บูรณาการการเรียน 6 ข้อ (ลำดับตายตัว)**: คุณลักษณะศตวรรษที่ 21 → โครงการ/ภารกิจ → สหวิทยาการ(ตามวิชา) → ทักษะวิชาชีพ(ตามวิชา) → Learning and Innovation Skills → Communication Tactic

## 4. กฎห้ามผิดเด็ดขาด
1. ทุกข้อ "กิจกรรมเชิงบูรณาการ" ขึ้นต้นด้วย "กิจกรรม" — ชื่อเปล่าดูไม่เป็นหลักการ (ผู้ใช้สั่ง 9 พ.ย.)
2. Day Camp ไม่มีครูในบรรทัดจำนวน (เว้นแต่ทีมติ๊กเปิดเอง)
3. ไม่มีตาราง/แถบสีในเอกสารลูกค้า (ยกเว้นใบเสนอราคา และ Run-down ภายใน)
4. รหัสเอกสารหน้าแรกหน้าเดียว
5. หมายเหตุกำหนดการสีแดง ปิดท้ายกำหนดการเสมอ
