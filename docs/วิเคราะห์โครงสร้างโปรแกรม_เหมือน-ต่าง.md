# วิเคราะห์ย้อนหลัง: โครงสร้างโปรแกรมค่าย EQ Camp
### อะไร "เหมือนกันทุกโปรแกรม" (โครงคงที่) vs อะไร "ต้องแก้ตามบรีฟ" (ตัวแปร)
อ้างอิงจากไฟล์จริง PL 0109/2569 (Math Camp อำนาจเจริญ 3 วัน 2 คืน) และ PL 0110/2569 (STEAM Camp ระยอง 2 วัน 1 คืน)

---

## ส่วนที่ 1 — จุดที่ "เหมือนกันทุกโปรแกรม" (ไม่ต้องแก้ / ระบบเติมให้เอง)

| องค์ประกอบ | รายละเอียดที่คงที่ |
|---|---|
| รูปแบบรหัสเอกสาร | `PL xxxx/2569` มุมขวาบน |
| หัวหลักสูตร | ชื่อไทยอยู่ในเครื่องหมายคำพูด จัดกึ่งกลาง + บรรทัดอังกฤษในวงเล็บ สีฟ้า |
| หัวข้อ (3 หัวข้อ เรียงเดิมเสมอ) | วัตถุประสงค์การเรียนรู้ → กิจกรรมเชิงบูรณาการ → บูรณาการการเรียน (integration instruction) |
| วัตถุประสงค์ ข้อ 3–4 | ข้อความตายตัว (เจตคติที่ดีต่อการเรียน / การเรียนรู้สร้างสรรค์ในศตวรรษที่ 21) |
| integration instruction | ข้อ 1–2 และ 3 ข้อท้าย (Collaborative & Leadership / Learning & Innovation / Communication) คงที่ |
| กิจกรรมปิดท้าย | "กิจกรรมทดสอบหลังการเรียนรู้ (After Action Review : AAR)" เป็นข้อสุดท้ายเสมอ |
| ตารางข้อมูล | จำนวน / วิทยากร / ระยะเวลาอบรม |
| โครงกำหนดการ | แถบวันสีน้ำเงิน, คอลัมน์เวลา, ลงทะเบียน/พิธีเปิด, นับมื้ออาหาร (1)(2)…, AAR, มอบของรางวัล/พิธีปิด, "พักผ่อนฝันดี", "เดินทางกลับ...โดยสวัสดิภาพ" |
| แบนเนอร์ราคา | "ราคาปกติ ~~x~~ ลดเหลือเพียง y บ./ท่าน" (ขีดฆ่าราคาปกติ) |
| โครงงบประมาณ | ที่พัก → อาหาร → อาหารว่าง → ห้องประชุม → วิทยากร → เดินทางวิทยากร → ทัศนศึกษา → อุปกรณ์ |
| ส่วนภาพ | "ตัวอย่างภาพกิจกรรม" + "ที่พัก [ชื่อสถานที่]" |
| ฟอนต์/กระดาษ | TH SarabunPSK, A4, ระยะขอบมาตรฐาน |

## ส่วนที่ 2 — จุดที่ "ต้องแก้ตามบรีฟ" (ตัวแปร → ระบบดึงจากบรีฟ/ให้เลือก)

| ตัวแปร | กระทบอะไรบ้างในไฟล์ |
|---|---|
| รหัส PL | หัวเอกสารทุกฉบับ (PL/QT/BK/RD) |
| โรงเรียน / ระดับชั้น / จำนวนนักเรียน-ครู | บรรทัด "จำนวน" + คำนวณจำนวนวิทยากรอัตโนมัติ + ยอดเงินรวม |
| **วิชา/ประเภทค่าย** | ชื่อหลักสูตร (ไทย+อังกฤษ), วัตถุประสงค์ข้อ 1–2, integration ข้อกลาง, **ชุดกิจกรรมทั้งหมด** |
| จำนวนวัน–คืน | ข้อความระยะเวลา + ความยาวกำหนดการ + จำนวนมื้ออาหาร |
| วันที่ / เวลาออกเดินทาง / ชั่วโมงเดินทาง | เวลาในกำหนดการทั้งหมด (คำนวณใหม่อัตโนมัติ) |
| **สถานที่ / จังหวัด / แหล่งทัศนศึกษา** | หัวกำหนดการ, ช่วงทัศนศึกษา, งบ "ที่พัก...คืน", หัวข้อภาพที่พัก, หนังสือขอราคาโรงแรม |
| ราคาปกติ / ราคาพิเศษ / ต้นทุน | แบนเนอร์ราคา, ยอดรวมใบเสนอราคา, กำไร/Margin (เอกสารภายใน) |
| กิจกรรมที่เลือก | ประโยค "กิจกรรมเชิงบูรณาการ" + ช่องกิจกรรมในกำหนดการ (เติมจนเต็มทุกช่อง) |
| ภาพกิจกรรม/ที่พัก | ช่องภาพ + คำบรรยาย (สร้างคำบรรยายตามบรีฟ แล้วใช้เป็นคำค้นภาพจริง) |

## ส่วนที่ 3 — ลำดับทำงานให้เสร็จใน 30 นาที
1. วางบรีฟ → "แปลงบรีฟ" (ดึงตัวแปรส่วนที่ 2 เข้าฟอร์ม + เตรียมช่องภาพ)
2. ตรวจ/แก้: หัวเอกสาร → เลือกกิจกรรม (เติมเต็มทุกช่อง) → กำหนดการ → ราคา
3. แท็บภาพ: "เติมช่องภาพตามบรีฟ" → "ค้นรูป" แต่ละช่อง → อัปโหลดรูปจริง (ฝังลงไฟล์)
4. ผ่านเช็กลิสต์ → ดาวน์โหลดเอกสารที่ต้องการ (โปรแกรม/ใบเสนอราคา/ขอราคาโรงแรม/Run-down ภายใน)

## ส่วนที่ 4 — เรื่องภาพจริง (ลิขสิทธิ์)
ระบบสร้างคำค้นภาพให้ตรงบรีฟและเปิดหน้าค้นหาให้ แต่ **ให้ทีมเลือกภาพที่มีสิทธิ์เผยแพร่เอง** (ภาพถ่ายค่ายจริงของทีม หรือสื่อทางการของโรงแรม) เพราะเอกสารนี้เป็นเอกสารขายที่แจกจ่ายต่อ การฝังภาพจากเว็บที่มีลิขสิทธิ์โดยไม่ได้รับอนุญาตมีความเสี่ยง — แนวทางที่ปลอดภัยและตรงงานจริงคือใช้คลังภาพของทีมเอง
